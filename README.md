## Entry

`main.ts` writes exactly one character to `/output/entry.txt`:

```text
A
```

`A` means coffee. Coffee wins: it is the louder, bolder, more alive answer — the drink that wakes you up and says so.

## Run

```sh
node main.ts
```

Deterministic: every run writes the same single byte, `A`, with no input, randomness, time, or network involved.
